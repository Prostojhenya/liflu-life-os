## ⚡ За 5 минут

```bash
# 1. Миграция данных (добавить memberIds в spaces)
npm install -D tsx
npx tsx scripts/migrate-memberIds.ts

# 2. Деплой новых правил Firestore
firebase deploy --only firestore:rules

# 3. Очистка мёртвого кода
bash cleanup.sh
```
