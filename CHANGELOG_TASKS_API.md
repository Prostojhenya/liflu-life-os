# Changelog: Tasks API Implementation

## Что было сделано

### 1. ✅ Создана типизация Task

**Файл:** `src/types/task.ts`

```typescript
interface Task {
  id: string;
  title: string;
  completed: boolean;
  xp: number;
}
```

### 2. ✅ Улучшен Backend API

**Файл:** `server.ts`

**Изменения:**
- Добавлена полная типизация для Task и CreateTaskRequest
- Добавлена валидация входных данных
- Добавлена обработка ошибок (404, 400)
- Добавлена константа DEFAULT_TASK_XP = 10
- Улучшены комментарии и структура кода

**Endpoints:**
- `GET /api/tasks` - получить все задачи
- `POST /api/tasks` - создать задачу (с валидацией)
- `POST /api/tasks/:id/complete` - завершить задачу (с проверками)

### 3. ✅ Обновлен Frontend API Client

**Файл:** `src/api/tasks.ts`

**Изменения:**
- Добавлены типы возвращаемых значений
- Добавлена обработка ошибок
- Добавлены JSDoc комментарии
- Функция `createTask` теперь принимает опциональный параметр `xp`
- Функция `completeTask` теперь возвращает Task с XP

### 4. ✅ Обновлен компонент Tasks

**Файл:** `src/components/Tasks.tsx`

**Изменения:**
- Импорт типа Task из `src/types/task.ts`
- Добавлено отображение XP для каждой задачи
- Добавлена анимация получения XP при завершении задачи
- Улучшен UI с бейджами XP

**Новые фичи:**
- При завершении задачи показывается уведомление "+X XP"
- Каждая задача отображает количество XP в бейдже
- Анимированное появление/исчезновение уведомления

### 5. ✅ Создана документация

**Файлы:**
- `API_DOCUMENTATION.md` - полная документация API
- `CHANGELOG_TASKS_API.md` - этот файл
