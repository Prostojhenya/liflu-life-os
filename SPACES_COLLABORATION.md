# Система совместной работы в пространствах

## Обзор

Liflu теперь поддерживает групповые пространства с возможностью приглашения участников для совместной работы над задачами, привычками и целями.

## Типы пространств

### 🔒 Личное пространство (Personal)
- Доступно только владельцу
- Идеально для личных задач и целей
- Создается автоматически при регистрации

### 👥 Групповое пространство (Shared)
- Поддержка нескольких участников
- Совместная работа над задачами
- Система ролей и приглашений

## Роли участников

### 👑 Владелец (Owner)
- Создатель пространства
- Полный доступ ко всем функциям
- Может приглашать и удалять участников
- Не может быть удален из пространства

### 🛡️ Администратор (Admin)
- Может приглашать новых участников
- Может удалять участников (кроме владельца)
- Полный доступ к задачам и контенту

### 👤 Участник (Member)
- Может создавать и редактировать задачи
- Может отмечать задачи выполненными
- Не может управлять другими участниками

## Как использовать

### Создание группового пространства

1. Откройте переключатель пространств (иконка в верхнем меню)
2. Выберите тип "Групповое"
3. Введите название пространства
4. Нажмите "+" для создания

### Приглашение участников

1. Откройте переключатель пространств
2. Нажмите на иконку ⚙️ рядом с групповым пространством
3. Введите email участника в поле "Пригласить участника"
4. Нажмите кнопку отправки

### Принятие приглашения

1. Приглашения отображаются в верхней части переключателя пространств
2. Нажмите "Принять" для присоединения к пространству
3. Или "Отклонить" для отказа

### Управление участниками

1. Откройте управление пространством (⚙️)
2. Просмотрите список всех участников
3. Удалите участника кнопкой 🗑️ (только для админов)

## Совместная работа

### Задачи
- Все участники видят общие задачи
- Любой участник может создавать задачи
- Любой участник может отмечать задачи выполненными
- XP начисляется тому, кто выполнил задачу

### Привычки
- Общие привычки для всей команды
- Каждый участник отслеживает свой прогресс
- Стрики считаются индивидуально

### Покупки
- Общий список покупок
- Любой участник может добавлять и отмечать покупки

### Цели
- Командные цели с общим прогрессом
- Все участники вносят вклад в достижение

### Чат
- Общий чат для всех участников пространства
- AI-ассистент доступен всем

## Безопасность

### Правила доступа
- Только участники пространства видят его содержимое
- Приглашения отправляются только по email
- Участник должен войти с тем же email, на который пришло приглашение
- Владелец не может быть удален из пространства

### Приватность
- Личные пространства полностью изолированы
- Групповые пространства видны только участникам
- История действий сохраняется для аудита

## Технические детали

### Структура данных

```
spaces/{spaceId}
  - name: string
  - type: 'personal' | 'shared'
  - ownerId: string
  - createdAt: timestamp
  
  /members/{userId}
    - userId: string
    - email: string
    - displayName: string
    - role: 'admin' | 'member'
    - joinedAt: timestamp
  
  /tasks/{taskId}
    - title: string
    - completed: boolean
    - spaceId: string
    - ...
  
invites/{inviteId}
  - spaceId: string
  - spaceName: string
  - email: string
  - invitedBy: string
  - inviterName: string
  - status: 'pending' | 'accepted' | 'rejected'
  - createdAt: timestamp
```

### Firestore Rules

Правила безопасности обеспечивают:
- Только участники могут читать данные пространства
- Только админы могут приглашать участников
- Только владелец/админы могут удалять участников
- Приглашения видны только отправителю и получателю

## Ограничения

- Максимум 50 участников в одном пространстве (можно увеличить)
- Приглашения действительны бессрочно (можно добавить TTL)
- Один пользователь может быть участником неограниченного числа пространств

## Поддержка

При возникновении проблем:
1. Проверьте правила Firestore
2. Убедитесь, что email совпадает с учетной записью
3. Проверьте роль пользователя в пространстве
4. Посмотрите логи в консоли браузера
