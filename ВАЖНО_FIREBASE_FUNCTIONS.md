# ⚠️ Важно: Деплой Firebase Functions

## Проблема
При попытке задеплоить Firebase Functions возникла ошибка:
```
Your project must be on the Blaze (pay-as-you-go) plan
```

## Что это значит?

Firebase Functions требуют **платный план Blaze** (pay-as-you-go).

### Почему нужен платный план?
- Cloud Functions - это серверный код, который выполняется на серверах Google
- Для запуска серверного кода нужен план Blaze
- **НО**: В плане Blaze есть бесплатная квота, которой хватит для вашего приложения

## Бесплатная квота Blaze плана

### Cloud Functions (бесплатно каждый месяц):
- ✅ **2 миллиона вызовов**
- ✅ 400,000 ГБ-секунд
- ✅ 200,000 ГГц-секунд
- ✅ 5 ГБ исходящего трафика

### Для вашего приложения:
- `checkScheduledNotifications`: ~8,640 вызовов/месяц (каждые 5 минут)
- `sendPushNotification`: зависит от количества уведомлений
- **Итого**: Далеко в пределах бесплатной квоты! 🎉

### Cloud Messaging:
- ✅ **Неограниченное** количество push-уведомлений (всегда бесплатно)

## Как обновить план

### Вариант 1: Через Firebase Console (рекомендуется)
1. Откройте: https://console.firebase.google.com/project/craftycode-mze7r/usage/details
2. Нажмите "Upgrade to Blaze"
3. Привяжите банковскую карту (для подтверждения)
4. Установите бюджетные лимиты (рекомендую $5-10/месяц для безопасности)

### Вариант 2: Через командную строку
```bash
firebase projects:list
firebase use craftycode-mze7r
# Затем обновите план в консоли
```

## После обновления плана

### 1. Задеплоить Functions
```bash
cd functions
npm run build
firebase deploy --only functions
cd ..
```

### 2. Проверить деплой
```bash
firebase functions:list
```

Должны появиться:
- ✅ `sendPushNotification`
- ✅ `checkScheduledNotifications`

## Альтернативное решение (без Functions)

Если вы не хотите использовать платный план, можно реализовать уведомления только на клиенте:

### Что будет работать:
- ✅ Мгновенные уведомления (когда приложение открыто)
- ✅ Локальные уведомления

### Что НЕ будет работать:
- ❌ Уведомления на заблокированном экране
- ❌ Запланированные уведомления (когда приложение закрыто)
- ❌ Push-уведомления через FCM

### Как реализовать:
Уже реализовано в `src/lib/notifications.ts` - функция `checkScheduledNotifications` на клиенте.

**Ограничение**: Работает только когда приложение открыто.
