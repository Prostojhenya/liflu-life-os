# 🚀 Быстрый деплой уведомлений

## Что исправлено
✅ Уведомления теперь приходят на **заблокированный экран**

## Деплой за 3 шага

### 1️⃣ Задеплоить Firebase Functions
```bash
cd functions
npm run build
firebase deploy --only functions
cd ..
```

### 2️⃣ Задеплоить приложение
```bash
npm run build
firebase deploy --only hosting
```
*Или если используете Vercel:*
```bash
vercel --prod
```

### 3️⃣ Проверить работу
1. Откройте приложение
2. Разрешите уведомления (иконка колокольчика)
3. Создайте задачу с напоминанием
4. Заблокируйте экран
5. Уведомление должно прийти! 🎉

## Что изменилось

### Серверная часть
- ✅ Добавлена функция `checkScheduledNotifications` - проверяет запланированные уведомления каждые 5 минут
- ✅ Обновлена функция `sendPushNotification` - теперь с поддержкой Android/iOS

### Клиентская часть
- ✅ Service Worker обновлен для показа на заблокированном экране
- ✅ Добавлен PWA манифест
- ✅ Автоматическое сохранение FCM токена

## Проверка после деплоя

### Проверить функции
```bash
firebase functions:list
```
Должны быть:
- `sendPushNotification`
- `checkScheduledNotifications`

### Проверить логи
```bash
firebase functions:log --follow
```

### Проверить FCM токен
В консоли браузера:
```javascript
const token = await getFCMToken();
console.log('Токен:', token);
```

## Важно для iOS
📱 На iPhone/iPad нужно:
1. Добавить сайт на домашний экран (Share > Add to Home Screen)
2. Открыть приложение с домашнего экрана
3. Разрешить уведомления

## Проблемы?

### Уведомления не приходят
1. Проверьте разрешения в браузере
2. Убедитесь, что FCM токен сохранен (Firestore > users > ваш_id > fcmToken)
3. Проверьте логи функций: `firebase functions:log`

### Service Worker не обновляется
1. DevTools (F12) > Application > Service Workers
2. Нажмите "Unregister"
3. Обновите страницу (Ctrl+Shift+R)

### Функции не деплоятся
```bash
cd functions
rm -rf node_modules package-lock.json
npm install
npm run build
firebase deploy --only functions
```
